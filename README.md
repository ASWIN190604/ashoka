# Ashoka Photostat & Printing Press

Professional Digital Printing Press & Production Studio in Rohtak, Haryana.

## Tech Stack
- React 19
- Vite 8
- Tailwind CSS 4
- Lucide React
- Framer Motion
- React Router DOM

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
